## Контрольные вопросы по гибридным вычислениям (CPU + GPU)

### 1. Какие преимущества предоставляют гибридные вычисления?

Гибридные вычисления предполагают совместное использование CPU и GPU в одном приложении. Основные преимущества такого подхода:

- **Максимальное использование ресурсов системы**: CPU и GPU выполняют те задачи, для которых они лучше всего подходят.
- **Повышение производительности**: вычислительно интенсивные и параллельные операции выносятся на GPU, а управляющая логика остаётся на CPU.
- **Снижение времени выполнения программ** за счёт параллельной обработки больших объёмов данных.
- **Гибкость разработки**: возможность комбинировать последовательные и параллельные алгоритмы.
- **Энергоэффективность**: GPU может выполнять массовые вычисления быстрее и с меньшими энергозатратами по сравнению с CPU.

---

### 2. Как минимизировать накладные расходы при передаче данных между CPU и GPU?

Передача данных между CPU и GPU является дорогой операцией, поэтому важно минимизировать её влияние:

- **Сокращение количества передач данных**, передавая большие блоки данных за один раз.
- **Перемещение вычислений на GPU**, чтобы избежать частых копирований туда и обратно.
- Использование **асинхронных копирований** (`cudaMemcpyAsync`) совместно с потоками CUDA.
- Применение **закреплённой (pinned) памяти** на стороне CPU для ускорения передачи данных.
- Перекрытие вычислений и передачи данных с помощью **CUDA streams**.
- Использование **Unified Memory** для упрощения управления памятью и снижения ошибок, когда это допустимо по требованиям к производительности.

---

### 3. Какие задачи лучше выполнять на CPU, а какие — на GPU?

**Лучше выполнять на CPU:**
- Задачи с **небольшим объёмом данных**.
- Алгоритмы с **сложной логикой управления** и большим количеством ветвлений.
- Последовательные операции и задачи с сильными зависимостями между шагами.
- Работа с вводом-выводом (файлы, сеть, пользовательский интерфейс).

**Лучше выполнять на GPU:**
- Массовые **параллельные вычисления**.
- Обработка больших массивов и матриц.
- Линейная алгебра, численные методы, моделирование.
- Обработка изображений, видео и сигналов.
- Алгоритмы редукции, сканирования, сортировки и фильтрации данных.

---

### 4. Как можно улучшить производительность гибридного приложения?

Для повышения производительности гибридного приложения можно использовать следующие подходы:

- Грамотное **распределение задач между CPU и GPU**.
- Минимизация передачи данных между устройствами.
- Использование **параллелизма на всех уровнях**: многопоточность на CPU и массовый параллелизм на GPU.
- Оптимизация доступа к памяти на GPU (coalesced access, shared memory).
- Подбор оптимальных параметров запуска CUDA-ядер (размер блока и сетки).
- Использование профилировщиков (например, **NVIDIA Nsight**) для выявления узких мест.
- Повторное использование данных, находящихся в памяти GPU, без лишних копирований.

Грамотно спроектированное гибридное приложение позволяет добиться значительного ускорения по сравнению с использованием только CPU или только GPU.
