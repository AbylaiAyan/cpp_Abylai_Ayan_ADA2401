## Контрольные вопросы

### 1. В чём разница между редукцией и сканированием?

**Редукция** — это параллельная операция, которая сводит набор элементов к **одному результирующему значению** с помощью ассоциативной операции (например, сумма, минимум, максимум).  
Пример: для массива `[1, 2, 3, 4]` результат редукции по сумме будет `10`.

**Сканирование (префиксная сумма)** — это операция, которая вычисляет **накопленный результат для каждого элемента массива**, используя ту же ассоциативную операцию.  
Пример: для массива `[1, 2, 3, 4]` результат сканирования будет `[1, 3, 6, 10]` (включающая префиксная сумма).

Основное отличие заключается в том, что редукция возвращает **одно значение**, а сканирование — **массив значений той же длины**, что и входной массив.

### 2. Какие типы памяти CUDA используются для оптимизации редукции и сканирования?

Для оптимизации редукции и сканирования в CUDA используются следующие типы памяти:

- **Глобальная память**  
  Основная память GPU, доступная всем потокам. Имеет высокую задержку доступа, поэтому прямые обращения к ней стараются минимизировать.

- **Разделяемая память (shared memory)**  
  Быстрая память, доступная потокам внутри одного блока. Активно используется для хранения промежуточных результатов при редукции и сканировании, так как значительно быстрее глобальной памяти.

- **Регистры**  
  Самый быстрый тип памяти, используется для хранения локальных переменных потока. Применяется для временных вычислений внутри ядра.

Использование разделяемой памяти позволяет существенно сократить количество обращений к глобальной памяти и повысить производительность алгоритмов.

### 3. Как можно оптимизировать префиксную сумму на GPU?

Оптимизация префиксной суммы на GPU возможна следующими способами:

- Использование **разделяемой памяти** для хранения промежуточных данных внутри блока.
- Применение эффективных алгоритмов, таких как **Hillis–Steele** или **Blelloch Scan**, которые хорошо параллелятся.
- Разделение задачи на несколько этапов:  
  - сканирование внутри блоков,  
  - редукция сумм блоков,  
  - добавление смещений к результатам каждого блока.
- Выбор оптимального **размера блока**, чтобы максимально загрузить GPU и минимизировать простои потоков.
- Минимизация операций синхронизации и ветвлений внутри ядра.

Эти методы позволяют значительно ускорить вычисление префиксной суммы на больших массивах данных.

---

### 4. Приведите пример задачи, где применяется сканирование.

Сканирование широко применяется в задачах параллельной обработки данных, например:

- **Сортировка** (алгоритмы radix sort и counting sort используют префиксные суммы).
- **Построение гистограмм** и вычисление смещений для записи данных.
- **Фильтрация массивов** (compaction), когда необходимо определить позиции элементов, удовлетворяющих условию.
- **Параллельная обработка изображений**, например при вычислении интегральных изображений.
- **Графовые алгоритмы**, такие как построение списков смежности.

Префиксная сумма является одной из базовых операций параллельного программирования и часто используется как вспомогательный этап в более сложных алгоритмах.
