# Контрольные вопросы

---

## 1. Как изменяется время выполнения программы при увеличении количества процессов? Почему?

При увеличении количества процессов время выполнения программы может как уменьшаться, так и увеличиваться. Для больших задач увеличение числа процессов обычно приводит к ускорению вычислений за счёт распараллеливания. Однако при фиксированном или малом размере входных данных время выполнения может увеличиваться. Это связано с накладными расходами на обмен данными между процессами и их синхронизацию. В среде Google Colab, где отсутствует полноценный вычислительный кластер, коммуникационные задержки часто превышают выигрыш от параллельных вычислений.

---

## 2. Какие факторы могут влиять на производительность программы?

На производительность параллельной программы с использованием MPI влияют следующие факторы:
- размер входных данных и объём вычислений;
- количество используемых процессов;
- накладные расходы на передачу данных и синхронизацию;
- используемые коллективные операции MPI;
- архитектура вычислительной системы и скорость межпроцессорного взаимодействия;
- баланс нагрузки между процессами.

---

## 3. Как можно оптимизировать передачу данных между процессами?

Оптимизация передачи данных между процессами может быть достигнута за счёт:
- уменьшения количества передаваемых данных;
- использования коллективных операций MPI вместо множества точечных передач;
- агрегации данных перед передачей;
- минимизации числа синхронизаций между процессами;
- равномерного распределения нагрузки между процессами;
- использования неблокирующих операций MPI.

---

## 4. Какие ограничения возникают при работе с большими данными?

При работе с большими данными возникают следующие ограничения:
- ограниченный объём оперативной памяти на каждом процессе;
- увеличение времени передачи данных между процессами;
- рост накладных расходов на синхронизацию;
- ухудшение масштабируемости алгоритмов;
- ограничения пропускной способности сети;
- необходимость более сложных схем распределения данных.
